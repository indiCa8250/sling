# Sling

Sling is a Flutter inventory and sales tracker for separate purchases.

Current features include:

- Separate purchase batches with editable labels and notes
- Sales, advances, repayments, waste, and weight checks
- Per-batch activity and statistics
- Completed-purchase history with combined past-sale statistics
- Android and Linux support

This project is being kept as a stable baseline. APK packaging and the future
website will be handled later.

## Run locally

```bash
flutter pub get
flutter run
```
